1. Start program.
2. Display a welcome message and purpose of the program.
3. Prompt user to enter total monthly income.
4. Initialize an empty list to store expenses.
5. Prompt user to enter expenses (categories and amounts).
6. Add each expense to the list until user indicates they are finished.
7. Calculate total expenses by summing amounts from the list.
8. Calculate savings as `Income - Total Expenses`.
9. If savings >= 0:
    a. Display the savings.
    b. Provide encouragement.
   Else:
    a. Display the deficit amount.
    b. Suggest categories to reduce costs.
10. End program.
